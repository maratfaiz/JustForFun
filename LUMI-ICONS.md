# Иконки Луми — что это и как вставлять

42 UI-иконки, которые заменяют SF Symbols в приложении. Это **не** маскот —
маскот и его сцены описаны отдельно в `LUMI-ASSETS.md`.

---

## 1. Что пришло

Наборов **два**, оба покрывают одни и те же 42 имени файлов — можно взять
любой и в любой момент поменять на другой, код трогать не придётся.

| Папка | Что это | |
|---|---|---|
| `assets/icons-phosphor/` | **Phosphor Icons**, вес Fill — готовый набор, залитые фигуры, лицензия MIT | ← рекомендую |
| `assets/icons/` | нарисовано кодом специально под Луми | |

**Почему рекомендую Phosphor.** Его рисовали профессиональные
иллюстраторы, в наборе 1512 иконок в шести весах. Это значит: отрисовка
ровнее, и когда понадобится 43-я иконка — она в наборе уже есть и встанет
в тот же стиль. У самодельного набора это плюс день работы.

**Когда брать самодельный.** Если захочется, чтобы иконки были ни на что
не похожи и совпадали с маскотом по «пухлости». Phosphor узнаваем — его
используют многие приложения.

### Три исключения из «залитости»

Набор взят в весе **Fill** — фигуры сплошные, детали внутри вырезаны
(так же, как у системных `*.fill` в iOS). Но три иконки залитыми быть не
могут или не должны:

* **`icon-freeze`** (снежинка) и **`icon-ambience-ocean`** (волны) — это
  линейные формы, у них нет внутренней площади. В весе Fill Phosphor
  заворачивает их в залитую плашку с вырезом, и получается кнопка, а не
  значок. Поэтому они остались контурными — рядом с залитыми смотрятся
  нормально, потому что сами по себе линейные.
* **`icon-heart-outline`** — специально контурное. Оно стоит в паре с
  `icon-heart-fill`, и если залить оба, они станут неразличимы.

### Две составные иконки

Таких в наборе нет, собраны из его же деталей: `icon-lumen` (кружок с
вырезанной звездой — на бренде, Луми же звезда) и `icon-critic-voice`
(пузырь с вырезанным восклицательным знаком).

У каждого набора есть цветная копия — `-colored`:

| Папка | Что внутри | Когда брать |
|---|---|---|
| `assets/icons-phosphor/` | **чёрный силуэт** на прозрачном фоне | основной вариант — цвет задаётся в коде |
| `assets/icons-phosphor-colored/` | тот же силуэт с запечённым цветом | если проще не возиться с tint |

Технические характеристики одинаковые:

| Параметр | Значение |
|---|---|
| Формат | PNG, RGBA |
| Размер | 1024 × 1024 px, квадрат |
| Фон | прозрачный |
| Цвет | один тон, без градиентов внутри иконки |
| Вес | 10–60 КБ |

## 2. Как подключать (важно)

Основной набор — **чёрный**. Чёрный цвет здесь ничего не значит: в iOS
шаблонная отрисовка использует только альфа-канал, а сам цвет берётся из
кода. Поэтому:

1. Положить PNG в `Assets.xcassets`.
2. У каждого имиджсета выставить **Render As: Template Image**
   (в инспекторе справа). Без этого иконка останется чёрной и
   `.foregroundColor(...)` не сработает.
3. В коде:

```swift
// было
Image(systemName: "flame.fill")
    .foregroundColor(.orange)

// стало
Image("icon-streak")
    .renderingMode(.template)   // можно и через Render As: Template в каталоге
    .resizable()
    .scaledToFit()
    .frame(width: 24, height: 24)
    .foregroundColor(streakOrange)   // #FF8A55
```

`.renderingMode(.template)` ставится сразу после `Image(...)`, до
`.resizable()`. Цвета из таблицы ниже удобно завести один раз — либо
Color Set'ами в `Assets.xcassets`, либо своим `Color(hex:)`.

Если Template-режим выставлять не хочется — брать файлы из папки с
суффиксом `-colored`, там цвет уже внутри, и `.foregroundColor` не нужен.

**Размер на экране.** Иконки нарисованы «в край» квадрата, без
встроенных полей. Ставить их в `.frame(width:height:)` 20–28 pt для
инлайновых значков, 28–32 pt для таб-бара, 40–56 pt для карточек
достижений и товаров магазина. Собственный отступ добавлять снаружи
через `.padding()`.

## 5. Лицензия Phosphor — что нужно сделать

Phosphor Icons распространяются по **MIT**. Использовать в коммерческом
приложении можно бесплатно, разрешения спрашивать не нужно, но лицензия
требует **сохранить текст копирайта** в продукте.

На практике это одна строчка на экране «О приложении» / «Благодарности»:

> Иконки — [Phosphor Icons](https://phosphoricons.com), лицензия MIT,
> © 2023 Phosphor Icons.

Полный текст лицензии лежит рядом с файлами: `assets/icons-phosphor/LICENSE.txt`.
Его достаточно показать в приложении в разделе с лицензиями.

Самодельный набор из `assets/icons/` в этом не нуждается — он ваш.

## 6. Откуда берутся файлы

### Самодельный набор

Иконки, как и маскот, **генерируются кодом** — `icons.py` на Pillow. Любую
можно пересобрать в другом размере или поправить форму, не открывая
редактор.

```bash
pip install pillow

# весь набор, чёрные силуэты, 1024 px
python3 icons.py --export assets/icons --size 1024

# тот же набор с запечённым цветом
python3 icons.py --export assets/icons-colored --size 1024 --colored

# одна иконка
python3 icons.py --one icon-streak --out /tmp/streak.png --size 512

# лист набора для проверки
python3 icons.py
```

### Как устроен файл

* Логическая сетка **512 × 512**, суперсэмплинг ×4, уменьшение LANCZOS —
  отсюда гладкие края. Любая координата проходит через `s()` / `sbox()`.
* Базовая толщина линии — `W = 38`. Менять её стоит только для всего
  набора сразу, иначе иконки рассинхронизируются по весу.
* Каждая иконка — функция, которая рисует в `L`-маску: `255` кладёт
  форму, `0` вырезает. Цвет накладывается один раз в конце, в
  `render_icon()`.
* Примитивы: `line`, `disc`, `ring`, `arc`, `rrect`, `poly` (с
  per-vertex скруглением), `sparkle`, `heart_pts`, `merged` (повернуть
  и подмешать), `clipped` (обрезать по маске).

### Как добавить иконку

```python
def icon_new(m):
    d = ImageDraw.Draw(m)
    ring(d, C, C, 158, 34)
    line(d, [(C, 166), (C, 346)], 36)

ICONS["icon-new"] = (icon_new, "#C9C2E6", "Описание для листа")
PRIORITY[3].append("icon-new")
```

### Набор Phosphor

Пересобирается из официального пакета — ничего не скачивается вручную:

```bash
npm pack @phosphor-icons/core && tar xzf phosphor-icons-core-*.tgz
npm install @resvg/resvg-js

node tools/phosphor_render.js package/assets /tmp/raw 1024 fill
python3 tools/phosphor_finish.py /tmp/raw assets/icons-phosphor
```

Последний аргумент — вес: `fill` (залитые, текущий вариант), `bold`
(контурные потолще), `regular`, `light`, `thin`. Пересобрать весь набор
контурным — это поменять одно слово в команде.

Соответствие «имя в приложении → имя в Phosphor» лежит в
`tools/phosphor-map.json`. Чтобы поменять любую иконку на другую из
набора — правится одна строчка в этом файле. Список исключений по весу —
`FORCE` в `tools/phosphor_render.js`.

## 7. Грабли

1. **Не забыть Template Image.** Самая частая ошибка — иконка вставлена,
   но остаётся чёрной, потому что имиджсет отрисовывается как обычная
   картинка.
2. **Не масштабировать непропорционально.** Файлы квадратные, ставить
   через `.scaledToFit()`.
3. **Не смешивать наборы.** Либо весь экран из `icons/` с tint, либо весь
   из `icons-colored/`. Иначе часть значков не будет реагировать на смену
   темы.
4. **Не перерисовывать поверх.** Если нужна другая форма — правится
   функция в `icons.py` и пересобирается набор, тогда толщина линии
   остаётся общей.
