# Карта персонажа: как устроен `cute_star.py`

Документ для того, кто правит звёздочку — человека или другой модели.
Схема с подписями: `anatomy.png` (генерится через `python3 make_anatomy.py`).

Правило номер один: **не рисовать поверх готовой картинки**. Всё собирается
из масок и заливок в порядке, описанном ниже. Если добавить деталь «поверх»,
она выпадет из силуэта и будет выглядеть наклейкой.

---

## 1. Система координат

* Все числа в коде — «логические», на холсте **1240×1240**.
* Рисуется всё в 3 раза крупнее (`SS = 3`), затем уменьшается LANCZOS —
  отсюда гладкие края. Функция `s(v)` переводит логическую координату в
  рабочую, `sbox(box)` — то же для прямоугольника. **Любая новая координата
  должна пройти через `s()` / `sbox()`.**
* Центр звезды: `CX, CY = 620, 566`. Ось Y смотрит вниз (как в экранных
  координатах), но `polar()` работает по-математически: угол против часовой,
  `90°` — вверх.

```python
polar(angle_deg, radius)  # -> точка вокруг (CX, CY)
```

---

## 2. Форма тела

`star_vertices()` возвращает 10 вершин: чередуются внешние (кончики лучей) и
внутренние (впадины между лучами).

| Что | Вершина | Как влияет |
|---|---|---|
| верхний луч | `polar(90, 312)` | длина верхнего луча |
| боковые лучи | `polar(17, 348)`, `polar(163, 348)` | размах в стороны |
| нижние углы | `polar(-56, 358)`, `polar(236, 358)` | ширина «бёдер» |
| впадины у верхнего луча | `polar(53, 200)`, `polar(127, 200)` | **толщина лучей**: больше радиус → звезда пухлее |
| боковые впадины (талия) | `polar(-24, 226)`, `polar(204, 226)` | толщина нижних лучей |
| вырез между ножками | `polar(-90, 240)` | больше радиус → вырез мельче |

`star_mask()` скругляет углы: `radii[i]` для i-й вершины (чётные — внешние
углы, нечётные — внутренние), `radii[4]`/`radii[6]` — нижние углы,
`radii[5]` — вырез между ножками. Скругление делает `round_polygon()` —
строит касательные дуги, трогать его не нужно.

## 3. Руки и ноги

Описаны кортежами в начале файла:

```python
ARM_DOWN = (218, 706, 76, 150, 10)     # dx, cy, ширина, высота, наклон
ARM_UP   = (259, 642, 76, 180, -50)    # поза "wave"
FOOT_W, FOOT_H = 112, 132
FOOT_DX, FOOT_CY = 100, 834
```

* `dx` — отступ от `CX`; левая конечность зеркалит правую (`CX - dx` и
  наклон с обратным знаком).
* Рука и нога — **капсулы** (`rounded_rectangle` с радиусом `w/2`):
  полукруг — прямой участок — полукруг.
* Наклон: положительный угол в PIL — против часовой. Для правой руки
  `+10` отводит низ наружу; `-50` поднимает руку вверх-вбок.
* Нижний конец конечности **обязан заходить внутрь тела**, иначе она
  «отклеится». Проверять по краю силуэта, а не на глаз.

### Как это собирается (важно)

```python
body  = star_mask(work)          # маска звезды
limbs = limb_mask(work, pose)    # маска рук и ног
mask  = ImageChops.lighter(body, limbs)   # ОДИН силуэт
draw_body(img, mask)             # общий градиент по всему силуэту
draw_limb_depth(img, body, limbs, tone, contact)
draw_face(img, mask, pose)
```

Конечности не рисуются отдельным цветом. Они объединяются с телом и
заливаются тем же градиентом, а читаются за счёт `draw_limb_depth()`:

* `visible = limbs - body` — только та часть, что торчит наружу;
* её подкрашивают темнее (`LIMB_SHADE`, сила `tone`);
* размытая маска тела кладёт на неё контактную тень (сила `contact`).

Пресеты силы — в `LIMB_DEPTH` (`none/soft/medium/strong`), флаг
`--limb-depth`.

## 4. Позы

`pose` протянут через `limb_mask()`, `draw_face()` и `render()`.
Сейчас есть `idle` и `wave`. Что меняет `wave`:

1. правая рука берёт параметры `ARM_UP` вместо `ARM_DOWN`;
2. `draw_motion_lines()` рисует две дуги у кисти (координаты `hx, hy` —
   центр «ладони», их нужно двигать вместе с рукой);
3. `draw_face()` берёт более широкую улыбку.

### Рецепт новой позы

1. Добавить кортеж вроде `ARM_UP` с нужными `dx, cy, w, h, tilt`.
2. В `limb_mask()` выбрать его по имени позы.
3. Если поза меняет лицо — ветка в `draw_face()`.
4. Добавить имя в `choices` у `--pose`.
5. Проверить рендером, что нижний конец руки утоплен в теле.

## 5. Лицо

Всё в `draw_face()`, координаты в логических единицах:

* глаза — `rounded_rectangle` на x = 533 и 722, блики смотрят к переносице;
* брови и улыбка — `d.arc(...)`. **PIL рисует толщину дуги внутрь bbox**,
  поэтому кружки-заглушки на концах ставятся по радиусу средней линии
  (`rx - width/2`, `ry - width/2`), иначе на концах появятся «шишки»;
* румянец — размытое пятно, обрезанное по силуэту (`mask=mask`), иначе
  вылезает на фон.

---

## 6. Грабли

* **Размывать нужно маску, а не RGBA-слой.** У прозрачных пикселей RGB
  чёрный, и `GaussianBlur` подмешивает его в цвет — блик уходит в грязно-
  оливковый. Для мягких пятен есть `soft_layer(size, color, alpha, painter,
  blur, mask)`: рисует силуэт в `L`-маске, размывает её и только потом красит.
* **Поворот тоже по маске** — `rotated_capsule()` крутит `L`-маску и лишь
  затем заливает цветом.
* Симметрия: всё привязано к `CX`, а не к абсолютным числам. Проверить можно
  так — bbox фигуры должен быть симметричен относительно центра:

```python
im = render(1240, transparent=True).getchannel("A")
x0, _, x1, _ = im.getbbox()
assert abs((x0 + x1) / 2 - 620) < 1
```
